# Fazenda_Inteligente
O projeto Fazenda IoT é um sistema de monitoramento e automação agrícola com ESP32, sensores ambientais e atuadores, usando MQTT. Os dados são enviados a um servidor Python, armazenados em MySQL e exibidos em dashboard web em tempo real. Permite controle remoto via celular, com modos automático e manual, sendo uma solução robusta e expansível.
